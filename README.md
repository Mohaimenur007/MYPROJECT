# MYPROJECT
## 🍽️ FoodShare – Secure Food Redistribution Platform

FoodShare is a web-based platform designed to connect food donors with charitable organizations, helping reduce food waste and improve food accessibility within communities. The platform enables donors to share surplus food efficiently while allowing charities to request and manage available donations.

### Key Features

* Food donation listing and management
* Request tracking and approval workflow
* User authentication and authorization
* Role-based access control (Donor, Charity, Admin)
* Activity monitoring and audit logging
* Secure session management
* Account lockout protection against brute-force attacks
* Two-Factor Authentication (2FA) for enhanced security
* Strong password validation and security controls
* Responsive and user-friendly interface

### Security Features

* Strong password policies
* Account lockout after multiple failed login attempts
* Two-Factor Authentication (2FA)
* Session timeout management
* Activity audit logs
* Threat detection and monitoring

### Tech Stack

* HTML5
* CSS3
* JavaScript
* Web Technologies
* Authentication & Authorization
* UI/UX Design

### Project Goal

To create a secure and efficient food redistribution system that minimizes food waste, supports charitable organizations, and contributes to building a more sustainable and socially responsible community.
